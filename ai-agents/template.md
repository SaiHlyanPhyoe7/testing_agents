Use this template when asking for code changes or agent guidance.

## Request Summary
- **Task:** A short sentence describing the goal.
- **Scope:** The files, components, or features involved.
- **Constraints:** Any requirements such as folder structure, libraries, or style.

## Example
- Task: Add Redux Toolkit state management to the React frontend.
- Scope: `frontend/src/App.jsx`, `frontend/src/app/store.js`, `frontend/src/features/counter/`
- Constraints: Use `axios`, keep Tailwind styles, and validate with `npm run build`.

## Response Expectations
- Use headings and bullets.
- Reference changed file paths.
- Keep the final summary concise.
